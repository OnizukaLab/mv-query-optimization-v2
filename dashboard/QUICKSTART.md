# 🚀 ダッシュボード クイックスタートガイド

## 5分で始めるMV Optimization Dashboard

### ステップ1: パッケージのインストール

```bash
# プロジェクトのルートディレクトリに移動
cd /Users/andersonkaina/Desktop/rs_system/mv-query-optimization

# 仮想環境の有効化（既に有効化されている場合はスキップ）
source .venv/bin/activate

# ダッシュボード用パッケージのインストール
pip install -r requirements-dashboard.txt
```

### ステップ2: ダッシュボードの起動

```bash
# ダッシュボードを起動
streamlit run dashboard/app.py
```

ブラウザが自動的に開き、`http://localhost:8501`にアクセスします。

### ステップ3: 初回設定

1. **設定ページに移動**
   - サイドバーから「⚙️ Settings」を選択

2. **データベース接続を確認**
   - デフォルト設定を確認
   - 「🔗 Test Database Connection」で接続テスト

3. **パス設定を確認**
   - Output Directory: `Output`
   - その他のパスが正しいか確認

### ステップ4: 最初の実験を実行

1. **ホームページに移動**
   - サイドバーから「🏠 Home」を選択

2. **実験を設定**
   - アルゴリズム: `Normal`, `BigSubs`, `Frequency`を選択
   - ストレージ制限: `50 MB`に設定
   - すべてのフェーズを有効化

3. **実験を実行**
   - 「🚀 Run Experiment」をクリック
   - 「▶️ Execution」タブで進行状況を確認

### ステップ5: 結果を確認

実験が完了したら:

1. **結果分析ページ**
   - 「📊 Results」で全体的な比較を確認

2. **クエリ分析ページ**
   - 「🔍 Query Analysis」で個別クエリの改善を確認

3. **MV Explorerページ**
   - 「📦 MV Explorer」で選択されたMVを確認

## 💡 便利なTips

### 設定の保存
- ホームページで「💾 Save Configuration」をクリック
- 次回は「📂 Load Configuration」で簡単に読み込み

### 複数アルゴリズムの比較
- 結果分析ページで比較したいアルゴリズムを選択
- グラフで視覚的に比較

### 結果のエクスポート
- 各ページの下部にエクスポートボタン
- CSV形式で保存可能

## 🔥 よくある質問

**Q: 実験が失敗する**
- データベースが起動しているか確認
- 設定画面で接続情報を確認

**Q: 結果が表示されない**
- 少なくとも1つの実験が完了しているか確認
- Output/ディレクトリにファイルがあるか確認

**Q: ダッシュボードが重い**
- フィルタリング機能を活用
- 表示するデータ量を制限
